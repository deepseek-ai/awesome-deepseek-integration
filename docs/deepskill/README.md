# DeepSkill

A battle-tested `AGENTS.md` skill file for **DeepSeek V4 Pro** that dramatically improves code quality and reliability of AI coding assistants.

## Features

- **5 Core Engineering Disciplines**: Risk Analysis, Self-Verification, Precision Operations, Environment Awareness, Completeness Assurance
- **Drop-in Ready**: Just copy one `AGENTS.md` file to your project or home directory
- **Compatible with**: opencode, Cursor, and any tool supporting `AGENTS.md` system prompts

## Quick Start

Copy `AGENTS.md` to your home directory for global effect:

```bash
# Linux / macOS
cp AGENTS.md ~/AGENTS.md

# Windows
copy AGENTS.md %USERPROFILE%\AGENTS.md
```
