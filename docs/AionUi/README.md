## English

> **A free, local, open-source multi-agent desktop app — bring your own DeepSeek API key.**

**AionUi** is a cross-platform (macOS / Windows / Linux) desktop client for working with multiple AI agents in one place. It connects DeepSeek alongside 20+ AI CLIs and any OpenAI-compatible API key, so you can chat, code, and run agents against DeepSeek models from a single local app — with your data staying on your machine.

Add DeepSeek by selecting the built-in **DeepSeek** platform and pasting your API key from the [DeepSeek Open Platform](https://platform.deepseek.com/). The base URL (`https://api.deepseek.com/v1`) is preset.

**Features:**
- **Bring your own DeepSeek key**: Built-in DeepSeek platform preset — paste your key and go.
- **Multi-agent workspace**: Run and switch between multiple agents and sessions side by side.
- **Any CLI & protocol**: Works with 20+ AI CLIs and supports MCP and ACP.
- **Local & private**: Conversations and data are stored locally on your device.
- **File preview & WebUI**: Preview files inline and access your workspace remotely via the built-in WebUI.

Repository: [iOfficeAI/AionUi](https://github.com/iOfficeAI/AionUi) · Website: [aionui.com](https://www.aionui.com)

## 简体中文

> **免费、本地、开源的多 Agent 桌面应用 —— 自带 DeepSeek API Key 即用。**

**AionUi** 是一款跨平台（macOS / Windows / Linux）桌面客户端，让你在一个应用里同时使用多个 AI Agent。它可接入 DeepSeek，以及 20+ AI CLI 和任意兼容 OpenAI 的 API Key，让你在本地应用中基于 DeepSeek 模型对话、写代码、运行 Agent，数据始终留在本机。

接入 DeepSeek 只需选择内置的 **DeepSeek** 平台，粘贴你在 [DeepSeek 开放平台](https://platform.deepseek.com/) 获取的 API Key 即可，Base URL（`https://api.deepseek.com/v1`）已预置。

**核心特性：**
- **自带 DeepSeek Key**：内置 DeepSeek 平台，粘贴 Key 即用。
- **多 Agent 工作台**：并排运行、切换多个 Agent 与多会话。
- **任意 CLI 与协议**：兼容 20+ AI CLI，支持 MCP 与 ACP。
- **本地私有**：会话与数据存储在本机设备上。
- **文件预览与 WebUI**：内联预览文件，通过内置 WebUI 远程访问工作区。

项目地址：[iOfficeAI/AionUi](https://github.com/iOfficeAI/AionUi) · 官网：[aionui.com](https://www.aionui.com)
