# [My Assistant](https://myassistant.aplusz.app/)

My Assistant is a polished chat client for your own API key. Paste a DeepSeek key and every call is shaped for DeepSeek: the reasoning model only on hard asks (code, maths, multi-step work, comparisons, long pieces), settings per task, a strict instruction contract for precise output, and retries that fit the API. File edits of any size come back byte-exact, and a separate pass checks that every part of your message was answered. Web app (installable), Google Play and Microsoft Store, 20 languages. The app costs €1.99 a month and takes no cut of your tokens; your key goes only to DeepSeek.

## Integrate with DeepSeek API

1. Open https://myassistant.aplusz.app/ and sign in with your email.
2. Settings → **Your AI** → paste your DeepSeek key. The app recognises the provider, checks the key with DeepSeek, stores it encrypted and shows your DeepSeek balance.
3. Tap 🔑 in the top bar to make it the answering key. Everyday questions go to `deepseek-chat`; hard asks switch to `deepseek-reasoner` by themselves.

## UI

Replies stream in with a "Thinking it through" line taken from DeepSeek's reasoning output, a code panel with copy and download, and a versions line for every file the model edits.
