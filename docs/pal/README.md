# [Pal - AI Chat Client](https://apps.apple.com/us/app/pal-ai-chat-client/id6447545085)

Pal is a customizable chat playground on iOS.

> **Note: The free version of Pal has extremely limited functionality.** For iOS, there is a better, more **BYOK** (Bring Your Own Key) style client, [ETOS LLM Studio (ELS)](https://github.com/deepseek-ai/awesome-deepseek-integration/tree/main/docs/ETOS-LLM-Studio), which offers significantly more features.
