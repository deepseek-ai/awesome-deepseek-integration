# [多问AI](https://www.duowen.app)

Hosted AI Q&A product (English brand Askmore). Users do not bring their own API keys; usage is billed in credits. It defaults to one main model, with optional web search and an answer-verification checklist. Attachments are preprocessed on the server.

Official site: https://www.duowen.app

## English

**How DeepSeek is used**

- Web search calls the official DeepSeek Search API.
- DeepSeek is also available as a catalog chat model (currently DeepSeek v4.1 Flash).

This is a hosted product: end users do not paste a DeepSeek API key into 多问AI. The service calls the DeepSeek API on their behalf.
