FateStar ([fatestar.top](https://fatestar.top)) is a Chinese metaphysics AI platform that combines Zi Wei Dou Shu (San He school), BaZi (Four Pillars), and Western astrology. Inference runs on DeepSeek-V4.

## Why DeepSeek

We evaluated several major LLMs on Chinese classical metaphysics texts. Models trained primarily on English-dominant corpora handle classical Chinese terminology and canonical text titles inconsistently in this niche.

DeepSeek handles terms like 「Hua Ji」, 「Lai Yin Gong」, and 「self-transformation Lu」 reliably, and its responses cite back to canonical texts such as *Zi Wei Dou Shu Quan Shu* without prompting tricks. That's why we standardized on DeepSeek-V4 for the full inference pipeline.

Three concrete reasons.

**1. Classical Chinese coverage.** Chinese cultural context is well-represented in DeepSeek's training data. Zi Wei terminology and canonical citations work out of the box, no fine-tuning required.

**2. 1M context window.** The Zi Wei canon (*Shi Ba Fei Xing Ce Tian Zi Wei Dou Shu Quan Shu*) is ~60K tokens. BaZi classics add ~120K. William Lilly's *Christian Astrology* adds ~200K. Total around 400K — well within DeepSeek-V4's 1M context, no chunking or RAG required.

**3. Thinking / Non-Thinking dual mode.** A Zi Wei luck-cycle inference is sequential: stem-revealing → Hua Lu/Hua Ji → self-transformation → Lai Yin palace → Major Limit / annual / monthly nesting. V4-Pro's Thinking mode streams the reasoning chain so the frontend can render it as a step-by-step explanation for the user.

## Integration details

- API endpoint: `api.deepseek.com/v1/chat/completions`
- Primary model: `deepseek-v4-pro` (Thinking mode) for deep inference
- Secondary model: `deepseek-v4-flash` (Non-Thinking) for fast chart generation and lightweight conversation
- Context window: 1M tokens
- Calling convention: function calling for structured chart JSON output, then chain-of-thought for inference

Data flow:

User birth time → astrology engine computes 144-star × 12-palace structured chart → DeepSeek-V4-Pro reads canonical text plus chart → outputs interpretation with citations to the original classical text.

The pipeline runs on FateStar's backend. DeepSeek accounts for approximately 90% of our inference cost.
