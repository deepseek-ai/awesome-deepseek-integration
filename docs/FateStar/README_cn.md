**FateStar** 是一款基于 DeepSeek 的 AI 命理平台, 主打 **三合派紫微斗数 + 八字 + 西洋星座** 三合一解读. 通过双轨干支算法 (真实万年历 + 紫微宫位编号双引擎) 与古书锚定 (太微赋 / 紫微斗数全书 / 十八飞星策天紫微斗数全书), 输出有出处、有逻辑、可复算的命理报告.

官网: <https://fatestar.top>

## 核心特性

- **三派合一**: 紫微斗数 (三合派单流派锁定) / 八字四柱 / 西洋占星, 一个平台覆盖东西方主流术数
- **双轨干支**: 真实万年历干支 vs 紫微宫位干支严格分离, 避免常见命理 App "宫位/历法混算"错误
- **古书锚定**: 解读引用太微赋、紫微斗数全书等古籍原文, 不让 AI 信口开河
- **DeepSeek 驱动**: 后端使用 DeepSeek-V3 / R1 做深度推理, 命盘 + 文言文古籍 + 现代白话翻译三层贯通
- **可逆算法**: 流年/流月/流日/流时/斗君/大限/小限 七维 Bijection (双射) 闭环, 公理证明 500+ 随机用例
- **隐私优先**: 用户出生信息加密存储, 命盘结果可本地导出, 不强制注册即可生成基础盘

## DeepSeek 集成方式

FateStar 使用 DeepSeek API 完成:

1. **命盘语义化**: 把 144 颗星曜 × 12 宫位的结构化数据翻译成用户能读懂的白话
2. **古籍交叉验证**: 用 DeepSeek R1 的长上下文能力同时读古文 + 命盘 + 用户提问, 给出有依据的回答
3. **流年推理**: 多步骤推理 (Chain-of-Thought) 用 DeepSeek 做透干 → 化禄忌 → 自化 → 来因宫 链式推导
