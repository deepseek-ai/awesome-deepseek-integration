## English

[Sol Next](https://github.com/chongyangzhang92-hub/Sol-Next) (`v0.1.0-beta`, Apache-2.0, authored by **Chongyang / 重阳**) is an open-source reference implementation of **System-0 Autonomous Mobile Agents** for **Android 10–16** *(HarmonyOS is not supported)*, published together with its companion research monograph (`paper/`).

- **Core Focus — Speed & Token Efficiency**: Zero-context-bloat skill crystallization (`ΔC_prompt = 0`, `5–200 ms`, `0` LLM tokens on repeated workflows), seven-layer critical-path speed architecture (`28.4 s → 3.82 s → 0.145 s`), and two-stage Rust/Kotlin UI-tree compression (`-90.7%` first-run tokens).
- **DeepSeek BYOK Integration (Zero Embedded Keys)**: Open **Settings → Model & API Providers**, select **DeepSeek** (or any OpenAI-compatible gateway such as Sub2API / New API / local Ollama), enter your own API key, and start immediately.
- **Links**: [GitHub & Paper](https://github.com/chongyangzhang92-hub/Sol-Next) · [Academic Homepage](https://chongyangzhang92-hub.github.io/Sol-Next/) · [v0.1.0-beta Release](https://github.com/chongyangzhang92-hub/Sol-Next/releases/tag/v0.1.0-beta)

## 简体中文

[Sol Next](https://github.com/chongyangzhang92-hub/Sol-Next)（`v0.1.0-beta` 第一版公开测试版，Apache-2.0，作者：**重阳 / Chongyang**）是面向 **Android 10–16**（*当前不支持鸿蒙系统*）的开源 System-0 自主移动智能体参考实现，同仓公开完整学术论文（`paper/`）。

- **核心竞争力——快与省 Token**：System-0 零上下文膨胀递归技能结晶（高频任务 `5–200 ms`、0 Token）、七层关键路径延迟工程（10 步任务 `28.4 s → 3.82 s → 0.145 s`）与双级界面树压缩（首跑省 90.7% Token）。
- **DeepSeek 自有密钥接入（零内置私密密钥）**：安装公开测试版后，在「设置 → 模型与 API 服务商」中选择 DeepSeek（或 Sub2API / New API / 本地 Ollama）填入自己的 API Key 即可使用。
- **相关链接**：[统一开源仓库（代码 + 论文）](https://github.com/chongyangzhang92-hub/Sol-Next) · [学术主页](https://chongyangzhang92-hub.github.io/Sol-Next/) · [v0.1.0-beta 下载](https://github.com/chongyangzhang92-hub/Sol-Next/releases/tag/v0.1.0-beta)
