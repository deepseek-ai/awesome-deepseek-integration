# Strait of Hormuz Simulator

A multi-agent geopolitical sandbox where 4 nations (Iran, US, Israel, Gulf States) are each controlled by an independent LLM agent. The free trial pool is powered by **DeepSeek V3**.

## Features

- 4 AI-driven nations with independent strategic doctrines
- 11 pluggable scenario modifiers (Nuclear Brinkmanship, Houthi Wildcard, etc.)
- Real-time oil market agent that prices in geopolitical risk
- SSE streaming to watch agents "think" in real-time
- Bilingual support (English/Chinese)
- BYOK supporting 8+ models including DeepSeek

## DeepSeek Integration

DeepSeek V3 powers the free trial pool, providing 20 free simulation rounds for users without API keys. DeepSeek models are also available as a BYOK option via LiteLLM.
