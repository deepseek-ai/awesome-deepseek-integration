# DeepSeek Toolbox

[Source code](https://github.com/Hamzaaw/deepseek-toolbox) · [Install from the Chrome Web Store](https://chromewebstore.google.com/detail/kengdooklhlonejpjiiiaeolnokhbhdf)

DeepSeek Toolbox is a free, open-source Chrome extension that adds organization and workflow tools directly to [DeepSeek's web chat](https://chat.deepseek.com).

- Group conversations into folders and pin useful messages.
- Save reusable prompts and run multi-step prompt chains.
- Export loaded conversations to Markdown, JSON, plain text, HTML, or a PDF print view.
- Select and delete multiple conversations.

## Use

Install the extension from the Chrome Web Store, open chat.deepseek.com, and sign in to DeepSeek. The toolbox appears in the sidebar. No DeepSeek API key is needed for these web-interface tools.

Folders, bookmarks, prompts, chains, and settings are stored in the browser. Optional AI prompt enhancement sends the selected draft to a separate hosted service; it is not a DeepSeek API integration. See the project's [privacy details](https://github.com/Hamzaaw/deepseek-toolbox/blob/main/PRIVACY.md).
