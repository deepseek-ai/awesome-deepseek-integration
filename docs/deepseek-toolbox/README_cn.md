# DeepSeek Toolbox

[源代码](https://github.com/Hamzaaw/deepseek-toolbox) · [从 Chrome 应用商店安装](https://chromewebstore.google.com/detail/kengdooklhlonejpjiiiaeolnokhbhdf)

DeepSeek Toolbox 是一款免费开源的 Chrome 扩展程序，为 [DeepSeek 网页聊天](https://chat.deepseek.com)添加对话整理和工作流工具。

- 使用文件夹整理对话，固定重要消息。
- 保存常用提示词，并运行多步骤提示词链。
- 将已加载的对话导出为 Markdown、JSON、纯文本、HTML，或通过浏览器打印视图保存为 PDF。
- 批量选择并删除对话。

## 使用方法

从 Chrome 应用商店安装扩展，打开 chat.deepseek.com 并登录 DeepSeek，即可在侧边栏中找到工具箱。这些网页界面工具不需要 DeepSeek API 密钥。

文件夹、书签、提示词、提示词链和设置保存在浏览器中。可选的 AI 提示词优化功能会将所选草稿发送到独立的托管服务，并非 DeepSeek API 集成。详见项目的[隐私说明](https://github.com/Hamzaaw/deepseek-toolbox/blob/main/PRIVACY.md)。

许可证：GPL-3.0-only。本项目独立开发，与 DeepSeek 无隶属关系，也未获其背书。
